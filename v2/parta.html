A1 · Handling characteristics and limitations of small craft

點解要學

考船最基本：船同車唔同，冇刹車掣、冇方向盤抓地力，要靠水流同螺旋槳。完全唔識操船嘅人最容易考錯呢部分。

核心知識

1. 機動性反應 (Manoeuvring characteristics)： - 細船反應快，但慣性大；放油門唔等於即時停 - 舵 (rudder) 要有水流經過才有效；停車時舵冇用 - Transverse thrust（橫推力）：螺旋槳轉動時，除咗推前外，仲會將船尾推向一邊 - 右旋單槳（right-handed propeller）正車：船尾推向右舷 - 右旋單槳倒車：船尾推向左舷 ← 呢個係考試重點 - 左旋槳相反 - 停船距離 (stopping distance)：細船一般要 3–6 個船長度才能完全停定 [src_pvoc_guide]

2. 大船同帆船嘅操控限制（要避讓佢哋）： - 大船：轉彎半徑大、停船距離長、視覺死角廣 - 帆船：依賴風向，可能突然轉向 (tacking/gybing) - COLREGS Rule 18：機動船一般要避讓帆船、捕魚船、操縱受限船 (RAM)、失控船 (NUC) [src_examrules]

3. 靠泊同離泊 (Berthing/unberthing)： - 頂流靠泊：船頭迎著水流方向 → 操控更精準 - 點解？水流提供額外舵效，可以慢慢推埋去碼頭 - 順流靠泊危險：船速 = 引擎速度 + 水流速度，難停 - 單槳船靠泊舷別：右旋單槳船建議左舷靠泊 (port side moor)，因為倒車時 transverse thrust 自然將 port 側推向碼頭

4. 擠迫水域 (Confined spaces)： - 慢車航行 + 預早通報意圖 - VHF 響聲號通知其他船

5. 惡劣天氣操控： - 用船頭側 (bow about 20–30°) 迎浪，唔好正頂浪 - 慢車前進，避免 broaching（橫擺翻側）、pitch poling（前後翻跟斗） - 順浪行駛速度要小心：船尾可能被浪打到失舵

6. 限制能見度（霧、暴雨）： - 減速到「最少能保持航向嘅速度 (minimum steerage way)」 - 開全部燈、發霧號（見 A6） - 加倍 lookout（見 A8）

考試重點

出題模式 答案要點
右旋單槳船靠泊邊一邊？ 左舷 (port side)——倒車時 transverse thrust 推 stern 向 port
頂流定順流靠泊？ 頂流——操控更精準
惡劣天氣航向？ 船頭側頂浪 (bow into seas at angle) + 減速
12 m 以下嘅船需唔需要顯示 NUC / RAM 號型？ 唔需要（diving operations 例外）COLREGS Rule 27(g)

易錯陷阱

  • 錯： 倒車時舵效會強——對： 倒車時舵效弱，要靠 transverse thrust
  • 錯： 順流靠泊節省燃油——對： 慳唔到，反而難控制
  • 錯： 全速頂浪最穩——對： 全速頂浪會 pitch poling，必須減速

A2 · Anchoring

點解要學

港內擠迫，下錨技巧錯就會走錨碰撞、或者錨纏住電纜要 cut anchor 棄錨。

核心知識

1. 揀錨地 (Selecting anchorage)： - 水深 + 海底質地：泥/沙最好（hold well），岩石/海草難 hold - Swinging room（迴旋空間）：船會圍住錨點轉，至少要 360° 半徑空間 - 避開電纜區、養殖區、航道、其他船嘅 swinging circle

2. Anchor scope（錨索長度）： - 香港 PVOC2 官方指引（考試答案）：「至少 4 倍水深」(at least 4× water depth or more) [src_pvoc_guide §2.4] - 國際 best practice 用 5:1–7:1（US/UK），更安全但 考試答 4× 先啱 - 例：水深 5 m，錨索至少 4 × 5 = 20 m（exam）；實務可放 25–35 m

3. 下錨步驟： 1. 預先 check 錨地、決定下錨點 2. 慢慢頂流接近，停船 3. 船開始輕微後退時放錨——避免錨直接落喺自己錨索上 4. 出夠 scope，鎖緊 windlass 5. Set anchor：輕輕倒車測試，確認錨咬實 6. 錨泊後檢查 leading marks 確定無走錨

4. 錨泊期間注意： - 顯示 anchor signals：日間 forward 一個黑球；夜間 white all-round light（細船 12 m 以下夜間錨泊喺指定 anchorage 內可豁免） - 定期 check leading marks / GPS 確認無走錨 - 留意風向同流向變化

5. 走錨 (Dragging anchor) 處理： - 立即啟動引擎避免漂向其他船或淺水 - 重新下錨（多放 scope，或者揀新位） - 通知 VTC 如喺繁忙水域

6. 纏錨 (Fouled anchor) 處理： - 試慢慢繞錨點打圈解開 - 唔得就要 cut anchor + 標記位置 + 報告海事處

7. 緊急下錨： - 失舵、失動力、火警等情況下用作止住船隻 - 例：失舵喺淺水區 → 立即下錨防擱淺（呢個係 A.37 考點）

考試重點

題目 答案
Anchor scope 官方答案？ 至少 4× 水深（PVOC guide）
失舵喺淺水區首要動作？ 立即下錨——防擱淺
揀錨地考慮邊三項？ 水深、海底、swinging room

易錯陷阱

  • 錯： 5–7× scope 係香港官方答案——對： 香港 PVOC guide 寫 4× 或以上；5–7× 係國際 rule of thumb
  • 錯： 走錨先慢慢諗——對： 立即啟動引擎控制船隻

A3 · Start up and close down safety checks

點解要學

考試會問航前 / 泊船後 check list；錯一兩項可能令你考唔過。

核心知識

1. 航前檢查 (Pre-departure check)： [src_examrules §8.1.A.3.a]

按官方 syllabus 4 大類：

(i) 天氣 (Weather) - 查香港天文台預報 (HKO) - 留意 typhoon / strong monsoon / thunderstorm signals - 揾本地實時 wind / wave 數據

(ii) 船身乾艙 (Compartment integrity) - Check bilge（艙底）有冇積水 - 開動 bilge pump 試 - Check 排水孔（scuppers）暢通

(iii) 救生 / 消防 / 遇險信號 (LSA / FFA / distress signals) - Lifejackets 數量足夠所有船上人員 - Lifebuoys（連 light + smoke）就位、易取 - Fire extinguishers 壓力錶綠色、未過期 - Distress signals（red flares、orange smoke）未過期

(iv) 航行設備 (Navigation equipment) - Compass（羅經） - Steering 全方向試 - 錨 + 錨索完整 - 纜繩 (mooring lines) 完整 - VHF radio 開機、check Channel 16 - 燈號（航行燈、停泊燈）全部 ok - 聲號設備（汽笛、bell）

2. 泊船後檢查 (Post-arrival check)： [src_examrules §8.1.A.3.b]

  • (i) Moored properly：纜繩夠多、夠長、有 fender
  • (ii) Compartments dry：bilge 抽乾
  • (iii) 設備收好：救生衣、纜繩、錨索 stow 妥
  • (iv) LPG cylinder 主閥關緊 — 防漏氣 + 火警
  • (v) 電池充滿——未來開機冇問題

考試重點

題目 答案要點
救生衣放邊？ 可即時使用 + 易取位置（A.36 考點）唔可以鎖喺櫃
泊船後關 LPG 邊個閥？ 氣樽主閥

易錯陷阱

  • 錯： 救生衣分佈兩舷就 OK——對： 必須易取、唔可以鎖入櫃
  • 錯： 泊好就唔使理 LPG——對： 必須關主閥防漏氣

A4 · Chart work, position fixing, ETA

點解要學

考試一定會出 1–2 題羅經換算 + 1 題定位 / 量距離。基礎數學題，但好多人輸喺 conversion direction。

核心知識

1. 海圖符號 (Chart symbols)： - 香港用 IMO Chart 1 同 Admiralty Chart 慣例 - Soundings（水深數字）以 metres + decimetres 顯示，下劃線表示乾出（drying height） - 浮標符號：詳見 A7 (local knowledge) 同 IALA Region A 系統

2. 定位 (Position fixing) 三大方法：

(a) Cross-bearing（交叉方位定位） - 同時量取 2–3 個岸上目標嘅羅經方位 - 喺海圖上由各目標反方向畫線 - 線交點 = 你嘅船位 - 三線唔交於一點 → 形成「cocked hat」誤差三角形，取中心估計

(b) Transit（重疊方位）/ Leading marks（導標） - 兩個固定點重疊成一線 = 一條極精準嘅 position line - 適合做 transit 嘅目標（A.30 考點）： - ✓ 點狀清晰物：燈塔、煙囪、雷達塔、山峰 - × 範圍模糊物：山脈、煉油廠、橋、船廠

(c) GPS / 電子定位 - PVOC2 唔深入，但須了解作為備用

3. 量距離 + ETA 計算： - 海圖上量兩點直線距離（用 latitude scale 1' = 1 nautical mile） - ETA = distance ÷ speed（單位：nautical miles ÷ knots = hours） - 注意潮流影響：vector diagram 求合速度

4. 羅經誤差 (Compass errors)： Note: 考試重點

名稱 來源 性質
Variation（磁差） 地球磁極 vs 真北 隨地點改變
Deviation（自差） 船上鐵磁影響 隨船向改變，查 deviation table

換算口訣 CADET（Compass → True 加 East）：

Compass → Magnetic → True
   +/- Deviation     +/- Variation
   East ADD          East ADD
   West SUBTRACT     West SUBTRACT

例（A.24 考題）： - Compass course 040° - Deviation 2°E、Variation 2°W - Magnetic = 040° + 2°(E) = 042° - True = 042° − 2°(W) = 040° ← 答案 D

5. 規劃短程航線 (Short passage planning)： - 起點 + 終點 + waypoints - 預計時間、燃油、潮汐 - 報備航行計劃畀岸上

6. 報告位置： - 經緯度（latitude / longitude）：北緯/東經，時/分/秒 - 或者「方位 + 距離」由已知 landmark：例「青衣燈塔西南 2 海里」

考試重點

題目 答案要點
Transit bearing 適合用咩物？ 點狀清晰物 + 點狀清晰物（如煙囪+雷達塔）
羅經換算口訣？ CADET：Compass + East = True 大
量距離單位？ Latitude scale, 1' = 1 nautical mile

易錯陷阱

  • 錯： 山脈做 transit OK——對： 範圍太大，唔精準
  • 錯： Variation/Deviation 加減方向亂咗——對： East 加，West 減（兩者都係）

A5 · Tides

點解要學

香港潮差雖然唔大（一般 < 2 m），但喺淺水區或者過橋底時都可能令船擱淺 / 撞橋。

核心知識

1. 潮汐成因： - 月球引力（主因）+ 太陽引力 + 地球自轉 - 香港屬「混合潮 (mixed semi-diurnal)」：每日 2 次高潮 2 次低潮，但高度唔等

2. 潮汐術語： - High Water (HW) = 高潮 - Low Water (LW) = 低潮 - Range = HW 高度 − LW 高度 - Spring tide（大潮）：新月或滿月期間，太陽 + 月球同向，range 最大 - Neap tide（小潮）：上 / 下弦月期間，太陽 + 月球互相 90°，range 最細

3. 香港潮汐資料： - Hong Kong Tide Tables（海事處出版）：每年印一次 - 海圖標記基準：Chart Datum (CD) 一般 = lowest astronomical tide - 海圖上水深數字 = 自 CD 起計，實際水深 = 海圖深度 + 當時潮高

4. Tidal stream（潮流）： - 流動方向 + 速度，隨潮汐改變 - 影響 ETA 計算（vector addition） - 香港某啲水道（如鯉魚門 Lei Yue Mun）潮流可達 3–4 knots

5. 規則粗判（rule of thumb）： - 漲潮 6 hr → 退潮 6 hr 循環 (semi-diurnal pattern) - 十二分之一規則（Twelfths Rule）：6 小時內 tidal range 變化分布 1/12 + 2/12 + 3/12 + 3/12 + 2/12 + 1/12

考試重點

題目 答案要點
大潮 / 小潮邊個 range 大？ 大潮 (Spring)
海圖深度 vs 實際深度？ 實際 = 海圖 + 潮高
Tide tables 邊個出？ 海事處 Marine Department

易錯陷阱

  • 錯： 海圖深度等於實際深度——對： 必須加上當時潮高
  • 錯： 香港冇潮差所以唔使理——對： Spring tide 仍可達 2.4 m

A6 · Navigation in restricted visibility

點解要學

香港夏天回南天霧、冬天有霾，能見度 < 1 海里時，碰撞風險急升。COLREGS Rule 19 + Rule 35 專管呢個情況。

核心知識

1. Safe speed（安全速度）—— COLREGS Rule 6：

決定 safe speed 嘅因素： - 能見度 (visibility) - 交通密度 (traffic density) ← A.13 考點 - 操縱性 (manoeuvrability) - 夜間燈光背景 - 風浪流 - 吃水 (draft) 對應水深 - Radar 性能（如有）

2. Rule 19（限制能見度行為）：

(a) 規則只適用於船隻喺霧 / 暴雨 / 降雪 / 濃煙等限制能見度水域時

(b) 每艘船都應： - 保持 safe speed - 主機隨時可即時操作 - 加倍 lookout（包括 radar）

(c) 聽到霧號明顯來自前方時： - 減速到 minimum steerage way - 必要時完全停船 ← A.14 考點 - 唔可以盲目轉向

(d) 若 radar 偵測到他船： - 早 + 大幅 改變航向 / 速度避碰 - 但 唔可以做以下動作（除非 overtaking）： - 對方喺 abeam 之前 (forward of beam)，向 port 轉 - 對方喺 abeam 或者 abaft 嘅，向佢方向轉

3. Rule 35（限制能見度聲號）：

每 ≤2 分鐘發一次：

船種 霧號
機動船 underway，making way 一長聲
機動船 underway，stopped 無對水移動 兩長聲（中間 ~2 秒）
NUC / RAM / 帆船 / 漁船 / 拖船 / CBD 一長兩短 ← A.11, A.12 考點
被拖船 一長三短（最後一隻發）
領港船 一長兩短後 + 4 短聲（區別）
錨泊船 ≥100 m 5 秒急鳴 bell（forward）+ 5 秒鑼 (gong) (aft) 每分鐘
錨泊船 < 100 m 5 秒急鳴 bell
擱淺船 3 響 bell + 5 秒急鳴 bell + 3 響 bell

記憶法：「I am special, give me space」= 一長兩短

4. 拖船特殊規則： - 拖船停咗都仍視為 underway（係拖緊嘢） - 所以停下無對水移動嘅拖船 仍係一長兩短而唔係兩長 ← A.12 考點

5. 限制能見度操作： - 開全部燈（夜間 + 日間都要） - 通知 VTC 你嘅位置同意圖 - 收聽 VHF distress channel 16

考試重點

題目 答案
帆船 underway 限能見度霧號？ 一長兩短（Rule 35(c)）
停咗嘅拖船霧號？ 一長兩短（仍 underway）
安全速度因素？ 交通密度等多項
聽到前方一長聲應該？ 立即減速到 minimum steerage way

易錯陷阱

  • 錯： 機動船霧號 = 一長兩短——對： 機動船 underway making way = 一長；special vessels (NUC/RAM/帆船/漁船/拖船) 才係一長兩短
  • 錯： 拖船停咗就用兩長——對： 拖船永遠當 underway = 一長兩短

A7 · Local knowledge (HK waters)

點解要學

呢個 topic 出題佔比好高（10+ 題），全部都係香港特有規則，國際 COLREGS 答唔到。背熟有著數。

核心知識

1. Victoria Harbour 範圍： 由維港東邊界（鯉魚門 Lei Yue Mun）至西邊界（青洲 Green Island），南北以海岸線界定 [src_visiting_yachts]

2. Fairways（主要航道）： 共 16 條 Principal Fairways + 2 條 TSS（分道航行制） [src_fairways]

MDN 75/2023（effective 2023-05-05）加入 Urmston Road、Castle Peak、Ha Pang 三條新 fairway，由原 13 條增至 16 條。Marine Department 官方 fairway page 已 reflect 此 update。

Note: 舊資料寫 10 條已過時——應使用 16 + 2 嘅新模型。考試以最新公報為準。

兩條 TSS： - Tathong Channel TSS（將軍澳東 — 鯉魚門外） - East Lamma Channel TSS（南丫島東） - COLREGS Rule 10 適用：船隻必須順 traffic lane 行駛，唔可以進入 separation zone（除非緊急或捕魚）

3. 禁止錨泊區 + 限制 / 禁止入區：

  • HKIAAA No. 1, 2, 3, 4 = 絕對禁區（除非處長批准）
  • HKIAAA No. 5, 6 = 船高限制 ≤ 15 m
  • HKIAAA No. 7, 8 = 船高限制 ≤ 30 m

法源：Cap. 313A 第 23 條 (6A) 款 + 第五附表第 5–12 段；違者第 3 級罰款 + 6 個月監禁 [src_cap_313a_5sch]

Note: Area 3 + 7 已於 2022-05-31 依 MDN 105/2022 修訂邊界（13 個新邊界 light buoys 建立），以配合機場三跑道系統 [src_mdn_105_2022]

記憶法：「1234 唔入、56 矮嘢入、78 高啲都入」

4. 速度限制 (Speed limits)： [src_speed_limit]

區域 限制 特別
Zone A（一般 typhoon shelter 入口附近） 5 knots
Zone B 10 knots
Zone C 15 knots
典型 typhoon shelter 入口或內 5 knots 14 個 typhoon shelters
K3 Hebe Haven / 白沙灣 5 knots 全年生效——其他季節性
Fairways 內 視乎標示 一般 10–15 knots

5. Traffic Separation Schemes 同 Rule 10： - 喺 TSS 行駛要順 traffic lane 方向 - 過 TSS 必須以接近 90° 角度過、唔可以斜過 - 唔可以喺 separation zone 內錨泊或捕魚 - 例外：(i) 緊急避免立即危險、(ii) 漁船捕魚（A.16 考點）

6. Ferry 路線 + 碼頭： - 港內天星小輪、離島渡輪等密集 - 公眾碼頭（Government public piers）：只准上落乘客 + 行李，不可裝卸貨物，不可長期 mooring ← A.23 考點 - 接近 ferry pier 要慢車 + 預讓 ferry

7. 安全康樂區 (Safe recreation areas)： - 遊泳浮台、康樂活動區 - 機動船禁止進入

8. 高速船燈號： - 香港高速船（如 TurboJET）日間顯示高速船標記；夜間顯示 high-intensity blue all-round light 喺最高位 + 一般機動船燈組

9. 香港帆船 junk lights： - 傳統 sailing junk 可能用煤油燈，較暗 + 可能少燈號 — 加倍小心避讓

10. 污染同棄置垃圾罰則： - 污染海水 / 棄垃圾入海事最高 HK$200,000 + 監禁 6 個月（Cap. 313） - 油污嚴重者罰則更高

11. IALA Region A buoyage system： - 香港用 IALA Region A（亞洲 / 非洲 / 歐洲體系） - 進港 (entering harbour)： - 紅色 can-shaped 浮標 = port hand mark = 保持喺左舷 (port) - 綠色 conical 浮標 = starboard hand mark = 保持喺右舷 (starboard) - 離港 (leaving harbour) = 相反 - Cardinal marks：N（黃黑 + 兩三角向上）/ S（黃黑 + 三角向下）/ E（黃黑 + 三角分向上下）/ W（黃黑 + 三角合中） - Isolated danger mark：黑色，2 個黑球 - Safe water mark：紅白條紋柱，1 個紅球 - Special mark：黃色 X 標誌

記憶法：「紅左綠右進港，相反離港」（A.26 考點）

12. 緊急援助： - VTC（船隻交通中心）：2233 7801（主線）；備用線兩個 source 不一：2233 7802（PVOC Guidebook）/ 2233 7808（GovHK Safety Tips）。打 7801 唔通可試兩個 [src_visiting_yachts] - MRCC（海事拯救協調中心）：2233 7999 - VHF Channel 16：國際遇險頻道

考試重點

題目 答案
HKIAAA 邊幾區絕對禁區？ Areas 1, 2, 3, 4
進港遇紅 can buoy 點過？ 保持喺 port 側通過
公眾碼頭可裝貨？ 不可
喺 TSS 邊個情況可入 separation zone？ 緊急避碰
Typhoon shelter 速度限？ 5 knots

易錯陷阱

  • 錯： 香港有 10 條 fairways——對： 自 2023-12-18 起係 16 + 2 TSS
  • 錯： HKIAAA 全部 8 區都禁入——對： 1-4 禁入，5-6 限 15 m，7-8 限 30 m
  • 錯： 紅 buoy = right of way——對： 紅 buoy = port hand mark，要保持喺左舷

A8 · COLREGS（國際海上避碰規則）

點解要學

PVOC2 出題最多嘅 topic（佔 Part A 約 1/3）。COLREGS 規則必須背熟核心 Rules 5–10、13–18、20–37。

核心知識

1. Rule 5 — Look-out（瞭望）：

「Every vessel shall at all times maintain a proper look-out by sight and hearing... so as to make a full appraisal of the situation and of the risk of collision.」

Look-out 嘅最主要目的：對局面同碰撞危險作出全面評估 ← A.15 考點

唔係單純睇浮標、能見度、漂浮物。

2. Rule 6 — Safe speed（見 A6）

3. Rule 7 — Risk of collision： - 用 radar、compass bearing、目視判斷 - Compass bearing 不變 + 距離縮短 = collision risk - 唔可以憑「scanty information」假設冇危險

4. Rule 8 — Action to avoid collision： - Early and substantial action（早 + 大幅） - Positive, clear and seaman-like manner（明確、清晰、合乎海員技藝） - 改變航向比改變速度更易被對方察覺 - Reduce speed 係合法避碰行動（A.1 考點）—— 唔需要硬撼或者轉向，可以減速 - Rule 8(e)：必要時停船 / 倒車 - Rule 8(f)：唔可以阻礙其他船嘅 passage / safe passage - Rule 8(f)(iii)：被阻礙嘅船仍須 take action

5. Rule 9 — Narrow channels： - 沿 channel 右邊行（starboard side） - ≤20 m 船 / 帆船 / 漁船唔可以阻礙只能喺 channel 內安全航行嘅大船 - 唔可以喺 channel 內錨泊（除非緊急） - 過 channel 要以接近 90° 角

6. Rule 10 — Traffic Separation Schemes（見 A7）

7. Rule 13 — Overtaking： - 後船由前船尾扇形 22.5° 後追上 = overtaking - 追越船永遠係 give-way 直至完全 past and clear - 即使後續變成 crossing 角度仍係 overtaking

8. Rule 14 — Head-on situation： - 兩艘 power-driven vessels 接近正面相遇 - 兩船都向 starboard 轉 - 從對方 port side 通過（red-to-red passing） - 一短聲 = 「I am altering my course to starboard」← A.6 考點

9. Rule 15 — Crossing situation： - 兩艘 power-driven vessels 交叉相遇 - 見對方喺自己 starboard 側 → 你係 give-way（要避讓） - 記憶法：「見右讓右」——starboard 右見 vessel = give way

10. Rule 16 — Action by give-way vessel： - 早 + 大幅 改變 - 完全避開 stand-on vessel

11. Rule 17 — Action by stand-on vessel： - (a)(i) 保持 course 同 speed - (a)(ii) 可以採取避碰行動（如見 give-way 唔讓） - (b) 緊急時必須行動 - (c) 機動船改向時，唔可以向 port 轉（如對方喺 port 側 crossing） - (d) 仍唔免除 give-way 嘅義務

當你係 stand-on 而對方已開始讓 → 保持 course + speed（A.18 考點）；唔好突然轉向打亂對方計算。

當對方 give-way 唔讓 → 5 短聲 doubt signal 警告（A.7 考點）

12. Rule 18 — Pecking order（誰讓誰）：

由 give-way 至 stand-on（即下方愈嚟愈大隻）：

1. Power-driven vessel
2. Sailing vessel
3. Vessel engaged in fishing
4. Vessel restricted in ability to manoeuvre (RAM)
5. Vessel not under command (NUC)

例外：條 9（窄水道）+ 條 10（TSS）+ 條 13（overtaking）優先於條 18。

13. Rule 19 — Restricted visibility（見 A6）

14. 燈號 (Lights) — Rules 20–31：

Power-driven vessel underway（機動船）

  • Mast head light：白色，前方 + 兩舷 22.5° 後共 225°
  • Side lights：starboard 綠 + port 紅，各前方 + 同舷 22.5° 後 共 112.5°
  • Stern light：白色，正後方 135°
  • ≥50 m 船：second mast head light（後 + 高過前）

Sailing vessel underway

  • Side lights + stern light 只
  • 冇 mast head light
  • 12 m 以下小帆船可以單一三色燈喺 mast top
  • 可以選擇性展示紅在上 + 綠在下喺 mast top（all-round）

Vessels at anchor

  • ≤50 m：一隻白 all-round light 喺 forepart
  • ≥50 m：forward 白 all-round + aft 較低白 all-round
  • 日間：forward 一個黑球 (black ball)

Vessels aground（擱淺）

  • 錨燈 + 兩個紅 all-round 垂直
  • 日間：3 個黑球垂直 ← 唔係遇險信號（A.25 干擾項）

Vessel not under command (NUC)

  • 兩個紅 all-round 垂直
  • 有 way through water：加 side lights + stern light
  • 日間：兩個黑球垂直

Vessel restricted in ability to manoeuvre (RAM)

  • Red-white-red all-round 垂直
  • 日間：球–菱–球 (ball-diamond-ball) 垂直 ← A.19 考試干擾項
  • 包括 dredging / surveying / launch & recovery / underwater operations

Vessel constrained by draught (CBD)

  • 機動船燈號 + 3 個紅 all-round 垂直
  • 日間：1 個圓柱形 (cylinder)

Fishing vessels

  • Trawling：綠 over 白 all-round + side lights + stern light
  • Other fishing（網、釣等）：紅 over 白 all-round + 視乎漁具情況加燈
  • 日間：兩個錐 (cones) 尖對尖

Pilot vessel

  • 白 over 紅 all-round + side lights + stern light
  • 日間：冇特定（屬機動船）

Towing

  • 拖船 mast head：2 個白 (towing length ≤200 m) 或 3 個白 (>200 m) 垂直
    • 機動船一般燈
    • Yellow towing light 喺 stern light 上方
  • 日間：拖長 >200 m → 兩船都係菱形 (diamond shape)

15. 號標 (Day shapes)：

形狀 意義
1 個球 forward 錨泊
3 球垂直 擱淺
球-菱-球垂直 RAM
2 個球垂直 NUC
1 個錐尖向下 帆船 + 用機動行進 (motor-sailing)
1 個圓柱 CBD
2 個錐尖對尖 漁船

16. 聲號 (Sound signals)：

短聲 = 1 秒；長聲 = 4–6 秒。

Manoeuvring & warning（Rule 34，能見度 OK）

信號 意義
1 短 "I am altering my course to starboard"
2 短 "I am altering my course to port"
3 短 "I am operating astern propulsion"（倒車）
5 或更多短，急 Doubt signal "I doubt your action is sufficient to avoid collision"
1 長 接近彎位 / 阻礙視線 / 駛離碼頭

Narrow channel overtaking（Rule 34(c)）

信號 意義
2 長 1 短 "I intend to overtake on your starboard side"
2 長 2 短 "I intend to overtake on your port side"
1 長 1 短 1 長 1 短 被追越船同意

Distress（遇險，COLREGS Annex IV）

(a) 槍聲或其他爆炸聲（每 1 分鐘 1 響） (b) 連續鳴笛聲 ← 遇險（A.25 考點） (c) 信號火箭、星彈 (d) 任何方法發 SOS（•••−−−•••）摩斯 (e) 「Mayday」廣播 (f) N over C 國際旗號 (Annex IV §1(f)) (g) 方旗 + 球（上方或下方）(Annex IV §1(g)) ← A.19 考點圖示最可能係呢個 (h) 船上有火焰 ← 遇險 (i) 紅色降落傘信號 (j) 橙色煙 ← 遇險（注意：白色煙唔係 distress） (k) 慢慢、有規律地伸縮兩臂 (l) DSC 遇險警告 (m) EPIRB 信號 (n) 其他無線電遇險信號

A.25 考點：邊啲信號可作遇險？ - 白煙 ×（橙煙才係） - 火焰 ✓ - 連續鳴笛 ✓ - 三個黑球垂直 ×（係 aground）

考試重點

題目 答案
Look-out 主要目的？ 全面評估局面同碰撞危險
Head-on 兩船點做？ 兩船都向 starboard 轉
Crossing：對方喺 starboard 點做？ 你係 give-way，要讓
Stand-on 見對方讓緊點做？ 保持 course + speed
12 m 以下船 NUC 號型免除？ 可免除（diving 例外）
帆船 underway 限能見度？ 一長兩短
窄水道 starboard 追越聲號？ 2 長 1 短
遇險信號邊個 NOT？ 白煙 + 三黑球（白煙非橙煙；三黑球係 aground）

易錯陷阱

  • 錯： Stand-on 永遠保持 course——對： 對方唔讓時要採取避碰
  • 錯： 三個黑球 = 遇險——對： 三個黑球 = aground
  • 錯： 白煙 = distress——對： 必須係橙煙

A9 · Safety equipment

點解要學

法律規定遊樂船必須配備 LSA（Life-Saving Appliances）+ FFA（Fire-Fighting Appliances）+ distress signals。考試會測知識 + 用法 + 維護。

核心知識

1. 法定要求 (Statutory requirements)： [src_pvoc_guide]

按 Cap. 548 + 細則，PVOC2 級遊樂船 (length ≤15 m) 須配備： - 救生衣（每人一件） ✓ - 救生圈（≥2 個，連 light + smoke + buoyant line） - 滅火器（按船長分配） - VHF radio - 紅色降落傘信號 + 橙色煙 + 手提火炬 - Bilge pump - Torch / 防水電筒 - 急救包

2. LSA 正確使用：

(a) Lifejackets（救生衣） - 每人一件、size 配身 - 兒童 / 嬰兒專用 size - 顏色顯眼（橙、黃） - 維護：定期 inspection 拉鏈、whistle、retro-reflective tape

(b) Lifebuoys（救生圈） - 至少 2 個，分置 port + starboard - 配備 self-igniting light + self-activating smoke + buoyant line - 用法：MOB（man overboard）即時拋落水（A.38 考點）

(c) Buoyant items：船上座位等亦可作浮力物（緊急時）

3. LSA 擺放原則： Note: A.36 考點

「可即時使用 + 易取位置」

唔可以： - 鎖入櫃 - 放座位下嘅深箱（需開啟） - 由船長個人喜好分配

4. LSA 維護程序： - 每年由 authorized agent 服務（lifejacket、lifebuoy retro tape、smoke canister 過期日期） - 每次出航前目視檢查 - 過期 immediately 換

5. Distress signals： （詳見 A8 + A.25）

(a) Red flares (hand-held / parachute)： - Hand-held：射程低，海面近距離求救 - Parachute：射程 ~300 m 高，遠距離

(b) Orange smoke signal： - 日間用，可飄 ~3 分鐘 - 白煙非 distress

維護：放防潮容器、check 過期日。

考試重點

題目 答案
救生衣放邊？ 可即時使用 + 易取位置
MOB 第一動作？ 拋救生圈 + 喊 + 指
邊啲滅火器適合電氣火？ CO₂（A.35 考點）

易錯陷阱

  • 錯： 救生衣分兩舷就 OK——對： 必須易取而唔係單純分布
  • 錯： 白煙係 distress——對： 必須橙煙

A10 · Use of VHF

點解要學

VHF 係海上溝通命脈。考試一定會問 channel 用途同遇險程序。

核心知識

1. VHF radiotelephone procedure：

接收： - 全程開機，monitor Channel 16 - 聽到 own callsign 即接

發送： - Press-to-talk (PTT) 後等 1 秒先講（避免 cut head） - 講嘅次序：對方 callsign → 自己 callsign → message → "OVER" - 話完成 = "OUT"

2. 香港 VHF 頻道體系： [src_vts_vscp]

Note: 絕對唔好簡化「CH 67 = 香港通用 incident channel」——香港有 5 個 sectors

Channel 用途
CH 02 Harbour East sector
CH 12 Eastern Approaches sector
CH 14 Harbour sector
CH 63 Lantau South sector
CH 67 Western Approaches sector
CH 16 國際遇險、安全、呼叫頻道
CH 20 Marine Department safety broadcasts（廣播）
CH 74 Kwai Chung Control Station (KCCS)——唔係 VTC sector

A.20 考點：題目顯示某地圖區域 → 答對應 sector 嘅 channel。如圖示為香港西邊水域（屯門、大嶼山西、大澳）→ Western Approaches sector → CH 67。但呢個係因區而異，唔係話 CH 67 係全港通用。

3. Distress 程序：

呼叫格式（VHF Channel 16）：

MAYDAY MAYDAY MAYDAY
This is [vessel name] [vessel name] [vessel name]
MAYDAY [vessel name]
Position: [latitude/longitude OR bearing/distance from landmark]
Nature of distress: [fire/sinking/MOB/grounding etc.]
Number of persons on board: [N]
Assistance required: [tow/rescue/medical etc.]
OVER

非 distress 但需要援助 = PAN-PAN PAN-PAN PAN-PAN（緊急但非生命威脅）

醫療緊急 = MEDICO（routine medical advice）

4. A.20 細節：嚴重受傷報告：

題目：圖示某區域 (Western Approaches)，船上嚴重受傷。用 CH 67 通報 VTC（屬該 sector 嘅頻道）。但若不知 sector，CH 16 係 fallback。

5. A.21 細節：違規舉報：

發現他船喺 speed-restricted zone 超速 → 致電 Harbour Patrol Section（手機），唔係 VTC。VTC 處理 navigational safety；Harbour Patrol 處理 enforcement。

6. A.9 細節：海事處船特殊聲號：

聽到海事處船發出一短一長兩短（汽笛）= 命令你立即停船。

考試重點

題目 答案
西區水域嚴重受傷用邊個 channel？ CH 67（Western Approaches sector）
國際遇險頻道？ CH 16
Speed zone 超速舉報？ Harbour Patrol Section（手機）
海事處船一短一長兩短？ 立即停船

易錯陷阱

  • 錯： CH 67 全港通用——對： CH 67 只係 Western Approaches sector
  • 錯： 超速舉報用 VHF——對： Harbour Patrol Section 手機

A11 · Marine Department services

點解要學

知道邊個部門做咩 + 點聯絡，緊急時唔會打錯電話。

核心知識

1. Vessel Traffic Centre (VTC)： [src_visiting_yachts]

  • 監察香港水域船隻動態
  • 發出 Radio navigation warnings (RNW)
  • 24/7 運作
  • 電話：2233 7801 / 2233 7808
  • VHF：5 個 sectors（見 A10）

2. Marine Rescue Co-ordination Centre (MRCC)： [src_mrcc]

  • 統籌 Search and Rescue (SAR)
  • 處理 Mayday / Pan-Pan
  • 電話：2233 7999
  • VHF：CH 16 + DSC

3. Notices to Mariners (NTM)：

  • 海事處出版，告知水域變更（新沉船、浮標移位、新規例）
  • 月報（permanent corrections）+ 即時公告（urgent notices）
  • 遊樂船船長有責任跟進

4. Marine Department Notices (MDN)：

  • 政策、規例、行政公告
  • 例：MDN 105/2022 修訂 HKIAAA Area 3 邊界

5. 緊急援助 cascade：

立即生命危險 → MAYDAY (CH 16) → MRCC 2233 7999
緊急但非生命 → PAN-PAN (CH 16)
航行警告 / 一般 → VTC 2233 7801 / 7808
違規舉報 → Harbour Patrol Section

考試重點

題目 答案
MRCC 電話？ 2233 7999
VTC 電話？ 2233 7801 / 7808
邊個處理 navigation warning？ VTC
海事處船汽笛一短一長兩短？ 立即停船（A.9 考點）

易錯陷阱

  • 錯： Mayday 打 VTC——對： Mayday 經 CH 16 → MRCC

A12 · Storm signals and weather

點解要學

香港夏天颱風頻繁，知道風球意義 + 相應行動先可以保命。

核心知識

1. 香港熱帶氣旋警告系統：

Signal 意義 相應海面
No. 1（戒備） 颱風 800 km 內 開始有 swell，能見度可能降
No. 3（強風） 預期香港陣風 41–62 km/h（持續 22–33 knots） 海面變壞，small craft 應入避風塘
No. 8 NW/SW/NE/SE（烈風 / 暴風） 持續風 63–117 km/h（34–63 knots） 絕對唔可以出海；已出海需立即返港
No. 9 / 10 風力 ≥ 118 km/h 颱風已襲港
強烈季候風信號 (Strong Monsoon Signal) 持續 22+ knots（東 / 南北季候風） 與 No. 3 類似海面，但成因唔係 tropical cyclone

2. Wave height 因素：（A.40 考點）

決定波高三大因素 (FSD)： - Fetch（吹程） ← 最關鍵 ← A.40 答案 A - Wind speed（風速） - Duration（吹咗幾耐）

錯選項：水溫、潮汐方向、濕度——都唔係主因。

3. 天氣資料來源： - HKO（香港天文台）官方網 + app - HKO marine forecast 每 6 小時更新 - VHF Channel 20 海事處廣播 - 地面風 + 海面風差異：海面通常風大過岸 30%

4. 解讀資料： - 風向 = 風由邊嚟（西南風 = 由西南吹來） - 浪向不一定同風向；可能 swell 由遠方傳來 - 留意「風力陣風 (gust) 高出持續風 30–50%」

5. 本地天氣 patterns： - 夏季：偏南氣流 + 颱風（5–10 月） - 冬季：東北季候風（11–4 月） - 春季：回南天霧（1–4 月，能見度可降至 < 100 m） - 夏季暴雨突發 + thunderstorm

6. Beaufort Wind Scale（蒲福風級）： 0–12 級

級 knots 海面狀態
0 <1 calm
3 7–10 gentle breeze, small wavelets
5 17–21 fresh breeze, moderate waves
7 28–33 near gale, white foam streaks
8 34–40 gale, moderately high waves
10 48–55 storm, very high waves
12 ≥64 hurricane

7. 颱風前準備（A.34 擴展）： - 移船入 typhoon shelter - 加 fender + 多條 mooring lines - LPG 主閥關閉 - Loose items 收落艙 - 喺擁擠 buoy mooring → 加 fender（避免 與其他船相撞）

考試重點

題目 答案
Wave height 主因？ Fetch
No. 8 風球海面點？ 絕對唔可出海
颱風前 buoy mooring 點做？ 加 fender（A.34）

易錯陷阱

  • 錯： No. 3 可以出海——對： No. 3 已 small craft warning，不宜出
  • 錯： 水溫決定浪高——對： Fetch + wind + duration

A13 · Handling of emergency situations

點解要學

緊急情況出題佔比高（A.13 / A.16 / A.34 / A.37 / A.38 等）。每種情況有 standard procedure。

核心知識

1. 碰撞 (Collision)：

立即動作： 1. 保持冷靜 + 戴上 lifejackets 2. 評估損壞：如 hull 破裂入水，啟動 bilge pump 3. 如有人受傷，提供急救 4. 書面報告海事處（Cap. 548 法定義務）← A.39 考點 5. 交換船名、船長姓名、保險資料 6. 唔可以未經處長同意離開現場

2. 擱淺 (Grounding)：（B.16 考點）

立即動作： 1. 停所有主機 2. 檢查機艙、主機、tail shaft 有冇損壞 3. 用 bilge pump 抽積水 4. 唔可以盲目加油門離開——可能毀壞 propeller / hull 5. 唔可以拋油 / 棄貨——污染海洋兼違法

正確答案組合 = (i) + (ii) + (iii)

3. 入水 (Leak)： - 即時定位漏點 - 用 emergency plug / wedge / 木塞堵 - Bilge pump 全開 - 如無法控制，發 distress + 戴 lifejackets

4. 火警 (Fire)： - 詳見 A.35（CO₂ 救電氣）+ B21 - 切斷燃料供應 + 通風 - 用適當滅火器 - 通知 MRCC

5. 失舵 (Loss of steering)：

A.37 考點：

淺水區失舵 → 立即下錨防擱淺 + 顯示 NUC 信號（兩紅燈或兩黑球）+ VHF 通知

深水區失舵： - 啟用 emergency tiller（如有） - 用 differential thrust（雙引擎船） - 拋 sea anchor 穩定船向 - VHF 通知 + 等拖救

6. 失動力 (Loss of propulsion)： - 如喺 channel → 立即下錨 - 顯示 NUC 信號 - VHF 通知 VTC

7. 失錨： - 用 spare anchor（如有） - 駛入安全水域 / typhoon shelter

8. Partial disable（部分失能）： - 視乎情況決定 self-rescue / 求救 - 慢車回港時持續 monitor 系統

9. 擱淺自救 (Beaching)： - 緊急情況下故意擱淺於沙灘救人 - 揀沙質淺灘避開岩石 - 順浪上岸 + 引擎及時停

10. 援助遇險船 (Assistance to vessels in distress)： - COLREGS 賦予義務（unless danger to own vessel） - 即使非本意亦可 invoke salvage law - 通知 MRCC

11. 操作員義務： - 操作期間不可飲酒 / 服用影響判斷藥物 - 確保所有乘客安全 - 維持 logbook

12. 穩性 / trim： - 重物均勻分布 - 避免 free surface effect（敞口液體晃動） - 啟航前確認 trim（船平衡）

13. Man overboard (MOB)： ← A.29 + A.38 考點

立即動作（口訣 STP）： 1. Shout "Man Overboard!" 通知全船 2. Throw lifebuoy（即時標示位置 + 提供浮力）← 首要動作（A.38） 3. Point：派專人持續指住落水者位置

之後： 4. 喊 throttle to neutral 5. Williamson Turn：硬轉（一邊全舵 60° 後，另一邊全舵 180°）→ 沿原航跡返 6. Reciprocal course = 原航向 + 180°（A.29 考點） - 例：SSE (157.5°) → reciprocal NNW (337.5°) 7. 接近 MOB 上風，停車救援 8. VHF Mayday 同 MRCC

考試重點

題目 答案
擱淺三件事？ (i)+(ii)+(iii)：停主機、檢查損壞、抽水
淺水失舵首要？ 立即下錨
MOB 首要動作？ 拋救生圈
SSE 反方向航向？ NNW（+180°）
颱風 buoy mooring 防護？ 加 fender

易錯陷阱

  • 錯： 擱淺加油門離開——對： 停主機 + 抽水 + 等救援
  • 錯： MOB 派人落水救——對： 先拋圈 + 用船救
  • 錯： 拋油令船浮——對： 違法 + 污染

A14 · Accident reports

點解要學

香港法律規定某啲海事意外必須書面報告海事處。考試會出邊啲意外要報。

核心知識

1. 必須書面報告嘅 reportable accidents： [src_examrules]

按 Cap. 548 + 細則： - ✓ 碰撞 (Collision)——船與船 / 港口設施 - ✓ 擱淺 (Grounding / Stranding) - ✓ 火警 / 爆炸 (Fire / Explosion) - ✓ 人員傷亡 (death, serious injury, missing persons) - ✓ 油污 / 海水污染 (Pollution) - ✓ 船舶失蹤 / 沉沒 (Loss / Sinking) - ✓ 失動力 / 失舵 喺繁忙水域（如導致 close-quarters situation）

2. 唔需向海事處書面報告嘅： ← A.39 考題

  • × 船員生病（屬醫療事項）
  • × 乘客錢包被偷（屬警方刑事案）
  • × 船上吵架（屬警方治安）
  • ✓ 船與港口設施碰撞 ← A.39 答案 D

3. 報告時限： - 一般 24 小時內以 form MD 嗰啲（具體 form number 視意外類別） - 嚴重者立即電話通知 + 後補書面

4. 報告內容： - 船名、註冊號、船長姓名 - 意外時間、地點、天氣、能見度 - 事件經過、損失、傷亡 - 採取嘅行動

5. 唔報嘅後果： - 罰款 + 監禁（Cap. 548 條文） - 影響牌照續期 / 申請

考試重點

題目 答案
邊樣意外要書面報？ 碰撞 / 擱淺 / 火警 / 傷亡 / 污染
A.39 邊個要報？ D 船 vs 港口設施碰撞

易錯陷阱

  • 錯： 偷竊都要報海事處——對： 偷竊報警，海事處唔處理
  • 錯： 細嘅碰撞唔使報——對： 任何碰撞都要報

Note: 重要 prerequisite：MD818 醫療證明（2025-06-30 起）

由 2025-06-30 起，所有 PVOC2 申請人（包括首次考試）都必須提供有效嘅 MD818 Medical Fitness Certificate。MD818 必須由 Marine Department 認可醫生簽發（清單見 https://www.mardep.gov.hk/filemanager/en/share/pub-services/pdf/list_rmp.pdf）。

11. PVOC2 同船牌嘅分別 Note: 重要

PVOC2 = 操作員 (person) 嘅資格證書。 唔等於可以揸船出海。

如要實際操作一艘船，仲需要： 1. 船嘅 Class IV operating licence（船牌） — 屬於船，唔屬於人 2. 第三者責任保險 — 至少 HK$5,000,000；如載 >12 個收費乘客則 HK$10,000,000 3. 規定下適用嘅其他批准（如商業用途、釣魚等）

法源：Cap. 548 Merchant Shipping (Local Vessels) Ordinance

呢個係好多人混淆嘅地方 — 拎咗 PVOC2 但用無牌船 = 一樣係違法。

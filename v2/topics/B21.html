B21 · Fire fighting and fire prevention

點解要學

火警喺船上是最致命災難之一。考試會出 4–5 題涵蓋火災理論、滅火器類型、燃料安全、LPG。

核心知識

1. Fire Triangle（火災三角）： Note: B.36 考點

    燃料 (Fuel)
       /\
      /  \
     /____\
燃燒溫度    空氣
(Heat)     (Oxygen)

3 元素缺一不可。 滅火 = 移除任何一邊。

B.36 答案 D：(i) + (ii) + (iii) 全部 = 燃料 + 空氣 + 燃燒溫度

2. 燃料火災危險：

(a) 汽油 (Petrol)： [src_examrules §8.1.B.21.a] - 揮發性極高，比空氣重，沉到艙底 - Flash point < 0°C — 室溫已易燃 - 4-min ventilation rule of thumb（唔係 PVOC 官方規則，但係國際 best practice）：開引擎前通風 4 分鐘

(b) 柴油 (Diesel)： - Flash point ~60°C，較安全 - 但仍可起火，霧化（spray）情況下尤其危險

(c) LPG（液化石油氣）： - 比空氣重 → 沉低處 → 通風口要喺底部

3. 火災分類 + 適當滅火劑： Note: A.35 / B.37 考點

Class 燃料 適當滅火 唔適當
A 木、紙、布 水、泡沫、乾粉 CO₂（無冷卻）
B 油、汽油、柴油、grease 泡沫、乾粉、CO₂ 水（油浮）
C 氣體（LPG） 乾粉、cut off supply 水
D 金屬 特殊 dry powder 水
E (電氣) 帶電器材 CO₂、乾粉 水、泡沫（導電）
F 食油 Wet chemical 水

Note: A.35 考點：電氣火警 = CO₂ 最佳（不導電、無殘留、唔損電子）

Note: B.37 考點：唔適合電氣火 = 泡沫（含水導電）

4. 攜帶式滅火器類型 + 操作 (PASS)：

操作 PASS 口訣： - Pull pin（拔保險銷） - Aim at base of fire（瞄火源底） - Squeeze handle（壓 trigger） - Sweep side to side（左右掃）

類型：

類型 內含 用 不用
Water 水 A 油 / 電氣
Foam 泡沫 A, B 電氣
CO₂ 二氧化碳 B, E A（無冷卻效果）
Dry powder 乾粉 A, B, C, E 食油
Wet chemical 化學液 F 電氣

5. 維護 (Maintenance)： - 壓力錶綠色區 - 每年由 authorized service agent 檢 - 操作後即重 fill / 換

6. 實戰滅火技巧： - 站上風（避免吸入濃煙） - 接近時保持低姿勢（熱氣浮高） - 設預定逃生路線 - 隊友支援 - 滅後監察 re-ignition

7. LPG 安裝同危險： Note: B.39 考點

規則： 1. ✓ 氣樽放陽光不直射處（避免溫升爆胎） 2. × 石油氣管「最短為原則」係錯！ 應有適當長度（避免拉緊或受損）← B.39 答案 B 3. ✓ 櫃內氣樽：櫃底必須有透氣管（LPG 比空氣重，沉底） 4. ✓ 氣樽存於甲板上

LPG 漏氣處理： - 立即關主閥 - 唔可以開電 / 火 / 火花 - 通風（強制 fan） - 用 soap-water 揾漏點

8. 安全燃油儲存 + 火警時隔離供應： - 油缸有 emergency shut-off valve - 甲板有 main fuel cock - 火警 = 即關 fuel supply

9. 燃油洩漏處理： - 即關 fuel valve - 用吸油布 / sand 吸 - 通風 - 唔可以用水沖（油浮會擴散） - 通報海事處（屬污染）

10. 加油 (Refuelling) 注意：

  • 引擎熄火
  • 乘客落船
  • 唔吸煙、唔開電
  • 加油後通風 4 分鐘（rule of thumb）才開引擎
  • 加完 check 漏

11. 機房防火措施： Note: B.38 考點

包括： - 定期檢查沙箱、滅火器 - 定期消防演習 - 定期操練 emergency fire pump

Note: 唔包括：發電機防過載——係維護事項而非防火措施。

B.38 答案 B

12. 排氣管隔熱： Note: B.20 考點

四大功能： - (i) 減熱輻射 - (ii) 降低機房溫度 - (iii) 防油類接觸引致火災 - (iv) 保護工人避免燒傷

全部都係，答 D

考試重點

題目 答案
電氣火警最佳滅火？ CO₂
唔適合電氣火？ 泡沫（含水導電）
火災三要素？ 燃料 + 空氣 + 熱
LPG 管長度原則？ 適當長度，唔係最短
機房防火唔包？ 發電機防過載（屬維護）
排氣管隔熱功能？ 4 個全部

易錯陷阱

  • 錯： 水可以救油火——對： 油浮喺水面會擴散
  • 錯： LPG 通風口喺頂——對： 底部（LPG 重）
  • 錯： 4-min vent 係 PVOC 官方規則——對： International rule of thumb

Part B 結語

呢 7 個 topics 覆蓋官方 syllabus 全部要求。

考前重溫策略

  1. B15 + B18（佔最多題）：背熟 4-stroke 循環、cylinder liner、common rail、故障診斷 framework
  2. B21 火警：背熟火災分類 + 適當滅火劑配對 + LPG 規則
  3. B17 電氣：防爆、容量、岸電接駁、觸電救援
  4. B16 監察：監察 7 項指標 + 油壓 / 水溫 / 排氣顏色 含義

故障診斷 mental framework

症狀 → 問四件事：
1. 燃料 OK？（油位、油喉、噴油器、carburettor jet）
2. 空氣 OK？（air filter、turbo）
3. 壓縮 OK？（valve、ring、liner）
4. 火花 OK？（汽油機 only：火花塞、distributor）
+ 冷卻 OK？（strainer、pump、thermostat）
+ 潤滑 OK？（油位、pump、filter）

A3 · Start up and close down safety checks

點解要學

考試會問航前 / 泊船後 check list；錯一兩項可能令你考唔過。

核心知識

1. 航前檢查 (Pre-departure check)： [src_examrules §8.1.A.3.a]

按官方 syllabus 4 大類：

(i) 天氣 (Weather) - 查香港天文台預報 (HKO) - 留意 typhoon / strong monsoon / thunderstorm signals - 揾本地實時 wind / wave 數據

(ii) 船身乾艙 (Compartment integrity) - Check bilge（艙底）有冇積水 - 開動 bilge pump 試 - Check 排水孔（scuppers）暢通

(iii) 救生 / 消防 / 遇險信號 (LSA / FFA / distress signals) - Lifejackets 數量足夠所有船上人員 - Lifebuoys（連 light + smoke）就位、易取 - Fire extinguishers 壓力錶綠色、未過期 - Distress signals（red flares、orange smoke）未過期

(iv) 航行設備 (Navigation equipment) - Compass（羅經） - Steering 全方向試 - 錨 + 錨索完整 - 纜繩 (mooring lines) 完整 - VHF radio 開機、check Channel 16 - 燈號（航行燈、停泊燈）全部 ok - 聲號設備（汽笛、bell）

2. 泊船後檢查 (Post-arrival check)： [src_examrules §8.1.A.3.b]

  • (i) Moored properly：纜繩夠多、夠長、有 fender
  • (ii) Compartments dry：bilge 抽乾
  • (iii) 設備收好：救生衣、纜繩、錨索 stow 妥
  • (iv) LPG cylinder 主閥關緊 — 防漏氣 + 火警
  • (v) 電池充滿——未來開機冇問題

考試重點

題目 答案要點
救生衣放邊？ 可即時使用 + 易取位置（A.36 考點）唔可以鎖喺櫃
泊船後關 LPG 邊個閥？ 氣樽主閥

易錯陷阱

  • 錯： 救生衣分佈兩舷就 OK——對： 必須易取、唔可以鎖入櫃
  • 錯： 泊好就唔使理 LPG——對： 必須關主閥防漏氣

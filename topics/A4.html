A4 · Chart work, position fixing, ETA

點解要學

考試一定會出 1–2 題羅經換算 + 1 題定位 / 量距離。基礎數學題，但好多人輸喺 conversion direction。

核心知識

1. 海圖符號 (Chart symbols)： - 香港用 IMO Chart 1 同 Admiralty Chart 慣例 - Soundings（水深數字）以 metres + decimetres 顯示，下劃線表示乾出（drying height） - 浮標符號：詳見 A7 (local knowledge) 同 IALA Region A 系統

2. 定位 (Position fixing) 三大方法：

(a) Cross-bearing（交叉方位定位） - 同時量取 2–3 個岸上目標嘅羅經方位 - 喺海圖上由各目標反方向畫線 - 線交點 = 你嘅船位 - 三線唔交於一點 → 形成「cocked hat」誤差三角形，取中心估計

(b) Transit（重疊方位）/ Leading marks（導標） - 兩個固定點重疊成一線 = 一條極精準嘅 position line - 適合做 transit 嘅目標（A.30 考點）： - ✓ 點狀清晰物：燈塔、煙囪、雷達塔、山峰 - ✗ 範圍模糊物：山脈、煉油廠、橋、船廠

(c) GPS / 電子定位 - PVOC2 唔深入，但須了解作為備用

3. 量距離 + ETA 計算： - 海圖上量兩點直線距離（用 latitude scale 1' = 1 nautical mile） - ETA = distance ÷ speed（單位：nautical miles ÷ knots = hours） - 注意潮流影響：vector diagram 求合速度

4. 羅經誤差 (Compass errors)： ⚠ 考試重點

名稱 來源 性質
Variation（磁差） 地球磁極 vs 真北 隨地點改變
Deviation（自差） 船上鐵磁影響 隨船向改變，查 deviation table

換算口訣 CADET（Compass → True 加 East）：

Compass → Magnetic → True
   +/- Deviation     +/- Variation
   East ADD          East ADD
   West SUBTRACT     West SUBTRACT

例（A.24 考題）： - Compass course 040° - Deviation 2°E、Variation 2°W - Magnetic = 040° + 2°(E) = 042° - True = 042° − 2°(W) = 040° ← 答案 D

5. 規劃短程航線 (Short passage planning)： - 起點 + 終點 + waypoints - 預計時間、燃油、潮汐 - 報備航行計劃畀岸上

6. 報告位置： - 經緯度（latitude / longitude）：北緯/東經，時/分/秒 - 或者「方位 + 距離」由已知 landmark：例「青衣燈塔西南 2 海里」

考試重點

題目 答案要點
Transit bearing 適合用咩物？ 點狀清晰物 + 點狀清晰物（如煙囪+雷達塔）
羅經換算口訣？ CADET：Compass + East = True 大
量距離單位？ Latitude scale, 1' = 1 nautical mile

易錯陷阱

  • 錯： 山脈做 transit OK——對： 範圍太大，唔精準
  • 錯： Variation/Deviation 加減方向亂咗——對： East 加，West 減（兩者都係）

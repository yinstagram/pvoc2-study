A9 · Safety equipment

點解要學

法律規定遊樂船必須配備 LSA（Life-Saving Appliances）+ FFA（Fire-Fighting Appliances）+ distress signals。考試會測知識 + 用法 + 維護。

核心知識

1. 法定要求 (Statutory requirements)： [src_pvoc_guide]

按 Cap. 548 + 細則，PVOC2 級遊樂船 (length ≤15 m) 須配備： - 救生衣（每人一件） ✓ - 救生圈（≥2 個，連 light + smoke + buoyant line） - 滅火器（按船長分配） - VHF radio - 紅色降落傘信號 + 橙色煙 + 手提火炬 - Bilge pump - Torch / 防水電筒 - 急救包

2. LSA 正確使用：

(a) Lifejackets（救生衣） - 每人一件、size 配身 - 兒童 / 嬰兒專用 size - 顏色顯眼（橙、黃） - 維護：定期 inspection 拉鏈、whistle、retro-reflective tape

(b) Lifebuoys（救生圈） - 至少 2 個，分置 port + starboard - 配備 self-igniting light + self-activating smoke + buoyant line - 用法：MOB（man overboard）即時拋落水（A.38 考點）

(c) Buoyant items：船上座位等亦可作浮力物（緊急時）

3. LSA 擺放原則： ⚠ A.36 考點

「可即時使用 + 易取位置」

唔可以： - 鎖入櫃 - 放座位下嘅深箱（需開啟） - 由船長個人喜好分配

4. LSA 維護程序： - 每年由 authorized agent 服務（lifejacket、lifebuoy retro tape、smoke canister 過期日期） - 每次出航前目視檢查 - 過期 immediately 換

5. Distress signals： （詳見 A8 + A.25）

(a) Red flares (hand-held / parachute)： - Hand-held：射程低，海面近距離求救 - Parachute：射程 ~300 m 高，遠距離

(b) Orange smoke signal： - 日間用，可飄 ~3 分鐘 - 白煙非 distress

維護：放防潮容器、check 過期日。

考試重點

題目 答案
救生衣放邊？ 可即時使用 + 易取位置
MOB 第一動作？ 拋救生圈 + 喊 + 指
邊啲滅火器適合電氣火？ CO₂（A.35 考點）

易錯陷阱

  • 錯： 救生衣分兩舷就 OK——對： 必須易取而唔係單純分布
  • 錯： 白煙係 distress——對： 必須橙煙

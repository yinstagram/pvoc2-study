B15 · Engines — Construction, pre-start, starting & stopping

點解要學

呢個 topic 係 Part B 嘅基礎，唔識引擎結構就讀唔通後面 6 個 topics。最少 5 題。

核心知識

1. Internal Combustion Engine (ICE) 兩大類：

Diesel（柴油） Petrol（汽油 / 船外機）
點火方式 壓縮自燃 (compression ignition) 火花塞點火 (spark ignition)
壓縮比 高 (15:1 to 22:1) 低 (8:1 to 12:1)
燃料 柴油（marine diesel oil, MDO） 汽油（PULP）
排氣 較髒（黑煙較多） 較乾淨
應用 大部分船內機（inboard） 細小船外機（outboard）

2. 4-stroke 循環： ⚠ B.1 圖解題核心

四個衝程，曲軸轉 2 圈完成一循環：

衝程 活塞方向 進氣門 排氣門 動作
1. Intake（進氣） ↓ 開 關 吸入空氣（柴油）/ 油氣混合（汽油）
2. Compression（壓縮） ↑ 關 關 壓縮
3. Power（動力） ↓ 關 關 燃燒推動
4. Exhaust（排氣） ↑ 關 開 排出廢氣

記憶法：「Suck, Squeeze, Bang, Blow」

B.1 答案 D（排氣）的圖示：活塞向上 + 排氣門開。

3. Cylinder liner（氣缸套）類型： ⚠ B.2 考點

Wet liner（濕式） Dry liner（乾式）
接觸冷卻水 ✓ 直接接觸 ✗ 套外仍有 engine block 壁
套壁厚度 較厚（要承水壓） 較薄（靠 block 支撐）
散熱效率 較佳（直接） 經 block 傳導
維修 易換 較複雜

B.2 答案 D：(i) 不接觸冷卻水 + (iii) 較薄 = dry liner 特徵。

4. 汽油機構造：

(a) Carburettor（化油器） — 將汽油霧化 + 混合空氣 - 噴口 (jet) 容易堵 → 加速無力（B.29 考點）

(b) Spark plug（火花塞） — 點火裝置

(c) Distributor（分火器） — 順序分配高壓電到各汽缸火花塞 - 4-stroke：分火器轉速 = 曲軸轉速嘅 1/2 ← B.4 考點 - 點解？4-stroke 一個循環曲軸轉 2 圈，每個汽缸只點火 1 次

(d) Choke（冷阻） — 啟動汽油機時： - 限制空氣 → 油氣混合變濃 (richer mixture) - 容易燃點 - ⚠ B.3 考點：題目問「節氣門 (throttle) 係咪用嚟令油氣混合更濃 / 易燃」 → 答 D：(i) (ii) 全不對——應該係 choke 而唔係 throttle

5. 柴油機構造：

(a) 燃油噴射系統 (Fuel injection)：

兩種： - Conventional（傳統）：燃油泵 → 高壓噴油管 → 噴油器 - Common rail（共軌）：高壓泵 → rail（蓄壓器）→ 噴油器 - 噴射壓力由 limiting valve 調節 ← B.5 考點 - 高壓泵打油到 rail，多餘油由 limiting valve 釋放回油缸 - 噴油器只負責噴射，唔調壓

(b) 燃油等級： - Marine diesel（船用柴油）— 一般係深褐色 - 紅色柴油 = 香港《應課稅品（碳氫油類標記及染色）規例》規定免稅工業 / 船用柴油 染紅，以區別於要稅嘅道路柴油 ← B.40 考點

6. 冷卻系統 (Cooling system)：

兩種：

(a) Direct (raw water) cooling：海水直接入引擎冷卻 - 簡單，但海水會腐蝕、結垢 - Thermostat 開啟溫度較低（避免海水結垢）

(b) Indirect (closed circuit) cooling： - 引擎用淡水冷卻 → 淡水經 heat exchanger 散熱到海水 - 引擎接觸淡水唔腐蝕 - Thermostat 開啟溫度較高

⚠ B.18 考點：兩種 thermostat 不可互換，因為：(i) 原理不同 + (ii) 操作溫度不同。答案 B。

7. Wet silencer（濕式消音管）系統： ⚠ B.8 考點

  • 引擎排氣管混入海水冷卻 + 消音 + 排出
  • 海水來源 = 引擎海水冷卻系統（B.8 答案 A）
  • 唔係 independent pump

8. Pre-start inspection 8 項： [src_examrules §8.1.B.15.b]

(i) Unrestricted movement — 螺旋槳唔會被纜繩、漁網纏住 (ii) Engine + propeller mounting integrity — 螺絲、bolt 牢固 (iii) Fuel oil system — 油位、油喉無漏 (iv) Lubricating oil： - Inboard：crankcase oil + gearbox oil - Outboard：gearcase oil（齒輪箱油） (v) Outboard 特殊：fuel/lube oil proportion — 2-stroke 船外機要混 oil 入汽油（一般 50:1） (vi) Cooling system — 海水入口 strainer 唔塞、淡水水位足夠 (vii) Engine + gearbox control — 油門、波檔測試 (viii) Steering gear — 全方位試

9. 啟動程序 (Starting procedures)： ⚠ B.14 考點

小型船外汽油機啟動 兩個首要步驟： 1. 將 lower unit / gearbox 降到水線以下（確保水冷系統有水） 2. 確認波檔在 neutral（避免啟動瞬間突然衝出）

之後： 3. 揸 choke（如冷機） 4. Open throttle 少少 5. 拉啟動繩 / 按 starter button

10. 啟動後即時要 check： ⚠ B.12 考點

  • (i) 冷卻水溫度錶：仍冷（剛啟動）
  • (ii) 潤滑油壓力錶：到設計壓力 (designed pressure) ← 答案
  • (iii) 轉速錶：idle（怠速），唔係 rated speed

11. 反覆 / 長時間啟動嘅影響： - 起動 motor 過熱 + 損耗 - 電池過度放電 - Cylinder 入過多油（柴油未燒）

12. Warming up + cooling down：

  • Warming up：低 RPM 怠速 5–10 分鐘，待 jacket water 達 ~60°C 才加負荷
  • 點解？避免 cylinder liner / piston 急速 thermal stress
  • Cooling down：到岸前低 RPM 5 分鐘
  • 點解？等 turbocharger（如有）冷卻 + 防止熱點 (hot spot)

13. 停車程序 (Stopping procedures)： ⚠ B.15 考點

柴油機正常停車 = 切斷燃油供應 (cut off fuel supply) - 唔係切空氣（air intake）—— 嗰個係 emergency - 唔係切電源 —— 柴油機冇火花塞，切電唔停 - B.15 答案 B

14. 機艙安全程序 (Securing machinery space)： - 關燃油 main valve - 關 sea cock（海水入口閥） - 切斷 battery main switch（如長期不用） - 通風確保無積聚易燃氣體

考試重點

題目 答案
4-stroke 排氣衝程？ 活塞 ↑ + 排氣門開
Dry liner 特徵？ 不接觸冷卻水 + 較薄
4-stroke distributor 速度？ 曲軸 1/2
Common rail 噴射壓力由邊個調？ Limiting valve
啟動小船外機首兩步？ Lower gearbox 入水 + neutral
啟動後油壓錶顯示？ 設計壓力
柴油機正常停車？ 切燃油
Wet silencer 海水來源？ 引擎海水冷卻系統
Choke 作用？ 令油氣濃 + 易燃；唔係 throttle
紅色柴油點解？ 應課稅品條例規定染色

易錯陷阱

  • 錯： 啟動汽油機用 throttle 變濃——對： 用 choke
  • 錯： 切電源停柴油機——對： 切燃油
  • 錯： Wet 同 Dry liner 散熱方式一樣——對： Wet 直接接觸水，Dry 經 block 傳

B16 · Duties while underway

點解要學

航行期間機房監察錯一啲，可能小事變大事故（過熱、油壓低、火警）。

核心知識

1. 監察引擎 7 項指標： [src_examrules §8.1.B.16.a]

指標 正常範圍 偏差含義
(i) RPM（轉速） 因引擎而異 過低 = 燃料 / 進氣 / 壓縮問題；過高 = 過載
(ii) 冷卻水溫度 80–95°C 一般 過高 = 冷卻不足；過低 = thermostat 卡 / cylinder 冷腐蝕
(iii) 冷卻水流量 視 spec 流量低 = strainer 塞 / pump fail
(iv) 潤滑油壓力 視 spec（一般 3–5 bar） 過低 = 漏 / pump fail / 油位低
(v) 潤滑油溫度 一般 < 90°C 過高 = 過載 / oil cooler 失效
(vi) 排氣溫度 視 cylinder 各缸不均 = injector 失效
(vii) 排氣顏色 淡灰 / 淡藍 黑 = 燃料過多；白 = 水入；藍 = 燒油

2. 引擎噪音 / 振動監察： - 異常 knocking = 燃燒 / bearing 問題 - 持續 vibration 可能 propeller 損 / mounting 鬆

3. 監察 stern gland + bilge level：

Stern gland（尾軸密封）： - 容許輕微滴水（1 滴 / 秒）潤滑 packing - 過量漏水 = packing 磨損，需 tighten gland nut（但唔可以過緊，會卡住軸）

Bilge level（艙底水位）： - 定時 check - 上升中 → 揾漏點 - Bilge pump 自動 trigger 嘅 float switch 要定期 test

4. 機房通風 (Machinery space ventilation)： - 強制 ventilation 確保引擎有足夠進氣 - 汽油機艙：通風尤其重要（汽油蒸氣易爆） - LPG 通風：氣比空氣重，通風口要喺底部

5. 機房常見問題： ⚠ B.6 + B.11 考點

B.6：吸海濾網 (sea suction strainer) 唔潔但引擎溫度正常？

可能原因： - (i) 溫度錶失靈（實際過熱但顯示正常） - (iv) 引擎負載很低（冷卻需求少）

答 D：(i) + (iv)

B.11：潤滑油壓力異常低？

可能原因： - (iv) 油壓錶失靈 - (v) 油泵嚴重磨損

答 D：(iv) + (v)

不會係： - (i) 過度冷卻——油黏稠反而壓力升 - (ii) 油位高——壓力反而升 - (iii) 輕微磨損——影響不大

6. 引擎理想工作狀態： ⚠ B.17 考點

「船體 + 螺旋槳匹配正確 = full throttle 達到 rated speed + full power」

如果 full throttle 達唔到 rated speed → propeller 過重；超過 rated speed → 過輕。

考試重點

題目 答案
強海濾網塞但溫度正常？ 錶壞 + 負荷低
油壓低主因？ 錶壞 + pump 嚴重磨損
引擎理想狀態？ Full throttle 達 rated speed + full power

易錯陷阱

  • 錯： 溫度正常 = 一定冇問題——對： 可能錶壞咗
  • 錯： Stern gland 完全唔漏先正常——對： 容許 1 滴/秒潤滑

B17 · Batteries and electrical equipment

點解要學

電氣事故可以致命（觸電、火警、爆炸）+ 引擎冇電 = 開唔到。考試會出 4–5 題。

核心知識

1. 電池 (Batteries) — 4 個監察項： [src_examrules §8.1.B.17.a]

(i) 充電狀態：用 hydrometer 量 specific gravity - 滿電 ~1.28；放電 ~1.15 - Voltage：12V 系統 滿電 12.6V，放電到 11.8V 已過低 (ii) 補充電解液：用蒸餾水（distilled water）補到 plate 上 1cm - ⚠ 唔可以加酸 (iii) 通風：充電產生氫氣（H₂）—— 易爆，必須通風 (iv) 充電電流：唔可以過大（會 overheating + 損極板）

2. 單元電池容量決定因素： ⚠ B.24 考點

「浸喺電解液裏嘅電池板表面面積」 決定容量 - 面積大 = 化學反應多 = 容量 (Ah) 大 - 不是 voltage（voltage 由 cell 數決定） - 不是充電時間（係 input 而非容量）

3. 電池室安全 — Explosion-proof equipment： ⚠ B.23 考點

電池充電產生氫氣（爆炸下限 ~4% in air）。

電池室任何電器（包括通風扇）必須係防爆型 (explosion-proof)。

唔可以用： - ✗ Drip-proof（防滴水） - ✗ Watertight（水密） - ✗ Weatherproof（防風雨）

B.23 答案 D。

4. Switchboard + 儀表 (Instrumentation)： - Voltmeter（電壓） - Ammeter（電流） - Battery condition indicator - Bus-bar 連接 main supply 同各 circuit - Circuit breaker（斷路器）+ fuse（保險絲）保護

5. Fuses — 功能、類型、額定值：

功能：當電流超過設計值 → 熔斷 → 保護電線同器材

類型： - Cartridge fuse（管狀） - Blade fuse（汽車 / 船多用） - HRC（high rupturing capacity）

額定值：標明電流（A）+ 電壓（V）+ breaking capacity

⚠ 燒咗 fuse 要換同樣 rating，唔可以用更大 rating（會燒線）

6. 觸電 (Electric shock) 應變： ⚠ B.27 考點

首要動作：切斷電源 (break the contact by switch off)

唔可以： - ✗ 直接拉傷者（你會跟住觸電） - ✗ 即施 CPR（電流仲喺度）

確認電源切斷後： 1. 評估呼吸 + 脈搏 2. 召喚 medical aid 3. 必要時 CPR

7. 接駁岸電 (Shore power) — 首要步驟： ⚠ B.26 考點

接駁前首要：關閉 (i) 碼頭供電箱主開關 + (ii) 船上配電系統開關

點解？ - 避免插拔時電弧 (arcing) - 避免短路 - 避免觸電

關閉次序：先船上、再碼頭，或者一齊都得。接駁好喉先重新開電。

考試重點

題目 答案
電池室通風 motor？ 防爆 (explosion-proof)
單一電池容量決定？ 電池板浸電解液面積
觸電救援第一步？ 切電源
接駁岸電前？ 關碼頭 + 船兩邊主 breaker

易錯陷阱

  • 錯： 防水 motor 可代替防爆——對： 必須防爆
  • 錯： 觸電即 CPR——對： 先切電源
  • 錯： Voltage 越高 = 容量越大——對： Voltage = cell 數；容量 = 板面積

B18 · Trouble shooting and remedies at sea

點解要學

船開出海冇人幫，自己要識診斷 + 暫時修。Part B 故障題佔 10+ 題。

核心知識

12 大常見故障 + 處理： [src_examrules §8.1.B.18]

(a) Difficulty in starting（啟動困難）

⚠ B.28 考點：以下邊個唔係柴油機啟動困難原因？

✓ Starter motor 轉得太慢（電池弱） ✗ 曲軸箱潤滑油不足（啟動唔依賴 crankcase 油）= 答案 B ✓ 空氣濾網阻塞 ✓ 燃油泵入空氣 (air lock)

(b) Engine stops underway（行駛中熄火）

可能原因： - 燃油用完 / 油喉塞 / 油泵 air lock - 過熱保護觸發 - Governor 失靈

(c) Speed fluctuation（速度波動）

可能： - 燃油供應不穩 - Governor 卡

(d) Engine vibration（振動）

可能： - 螺旋槳損 - 排氣失壓 - Mounting 鬆 - 噴油器某個失靈（有缸冇噴油）

(e) Turbocharger vibration

  • Bearing 磨損
  • Compressor wheel 損

(f) 異常排氣 — 黑、白、藍煙：

顏色 原因
黑 燃料過多 / 空氣不足（air filter 塞、turbo 失效）
白 水入 cylinder（gasket 漏 / liner crack）/ 太冷（未燒完）
藍 燒潤滑油（piston ring 磨損 / valve guide 漏）

(g) High lube oil temp

  • Oil cooler 塞
  • 過載
  • 油路 restriction

(h) High coolant temp / low flow

  • Strainer 塞
  • Pump impeller 損
  • Thermostat 卡關

(i) High exhaust temp

  • 過載
  • 噴油時間 (timing) 錯
  • Compression loss

(j) Gear engaging difficulties

⚠ B.7 考點：高速時 clutch 打滑可能原因？

✓ 離合碟磨損 (ii) ✓ 油壓過低 (iii) ✗ 工作溫度太低 (i) — 唔係 slip 主因

答 D：(ii) + (iii)

(k) Engine fails to stop

  • 燃油 cut-off 機構卡
  • Emergency = 切空氣供應 (stop air intake)

(l) Bilge pumping efficiency 下降

  • Strainer 塞
  • Pump impeller 磨損
  • Air leak（吸唔起水）

⚠ B.22 考點 — Piston pump 圖示

手動活塞泵：推手柄時 = 壓縮衝程 - Inlet valves 關閉、outlet valves 打開 - 答案 B：valves 2, 3 關（具體編號參照官方圖）

B.10 考點 — 低壓油管入空氣後果：

  • (i) 引擎振動（噴油不均）
  • (iii) 啟動失敗（油泵打唔上壓）
  • 唔會 (ii) 噴油系統過熱

答 D：(i) + (iii)

B.13 考點 — 液壓舵機 air lock 原因：

  • (i) 接頭漏 → 油走 + 空氣入
  • (ii) 油量不足 → 系統吸入空氣

兩個都對，答 C

B.19 考點 — 油壓警報響：

首要：將引擎減速 (reduce speed) — 保護引擎，再判斷情況

唔好： - 立即停機（船會失控漂） - 繼續正常運行（會損 bearing） - 加油（治標不治本）

B.21 考點 — 入排氣閥間隙不足：

→ 閥門關不緊 → 壓縮氣體洩漏 → 失壓縮（Loss of compression）

⚠ 唔係 noisy tappets —— 嗰個係間隙過大

B.29 考點 — 船外汽油機加速失敗：

→ 化油器噴口 (jet) 有污物 = 油不足 = 加速無力

其他選項： - (A) 油 / 油混合比例 — 影響潤滑非加速 - (C) 油喉冇 priming — 完全唔啟動 - (D) 點火系統故障 — 通常完全唔著火

B.30 考點 — 噴油器漏：

後果： - (i) 馬力下降 - (ii) 黑煙 - (iii) 振動 - (iv) 多耗油

全部對，答 D

B.31 考點 — 氣缸過冷 (super-cooled jacket water)：

→ 燃燒不完全 → 酸性產物凝結 cylinder 壁 → cold corrosion → 磨損

呢個係最易磨耗原因。

B.32 考點 — 失壓縮原因：

→ Exhaust valve 卡開（Exhaust valve stuck open）= 壓縮氣體從排氣口漏走

唔係： - 燃油等級錯 — 影響燃燒非壓縮 - Manifold 漏 — 影響進排氣量

B.33 考點 — 汽油機排氣較乾淨：

✓ (ii) 易達完全燃燒 ✓ (iii) 汽油碳含量低 ✓ (iv) 汽油易點火 ✗ (i) 燒少 — 汽油機單位功率燒得多

答 C：(ii)+(iii)+(iv)

B.34 考點 — 柴油機氣缸過量潤滑：

  • (i) 易結碳（多餘油喺燃燒室燒成積碳）
  • (ii) 活塞環卡死（積碳令 piston ring stuck）
  • (iii) 增加磨損 — ✗ 過度潤滑反而減磨損
  • (iv) 過載 — ✗ 唔關過載事

答 A：(i)+(ii)

B.35 考點 — 甲板絞車液壓油位過低：

→ 隔離絞車 + 檢查油喉漏點

唔好： - 即注油 — 浪費油 - 排積水 — 油減少 ≠ 入水 - 釋壓 — 唔關膨脹事

其他常見：B.16 擱淺處理（見 A.13）

考試重點

故障題太多，記呢個 mental framework：

「症狀 → 詢問：燃料？空氣？壓縮？火花？冷卻？潤滑？」

症狀 最大可能原因
啟動唔到 Battery / 燃油 air lock / 空氣濾網塞
加速無力 Carburettor jet 塞 / 燃料不足
黑煙 燃料過多 / 空氣不足
白煙 水入 cylinder
藍煙 燒潤滑油
過熱 Strainer 塞 / pump fail / thermostat 卡
失壓縮 Exhaust valve 卡開 / 閥間隙不足
Cylinder 磨損 過冷 cold corrosion
油壓低 錶壞 / pump 嚴重磨損
油壓警報 減速（唔係即停）

易錯陷阱

  • 錯： 油壓警報立即停機——對： 先減速
  • 錯： Cylinder 過熱最磨損——對： 過冷最磨損（cold corrosion）
  • 錯： 閥間隙過大失壓縮——對： 過大係 noisy tappets；過細先失壓縮

B19 · Maintenance

點解要學

定期 maintenance 預防 90% 故障。考試會問 maintenance schedule + 具體項目。

核心知識

1. Maintenance schedule 來源：

  • 船廠（shipbuilder）maintenance manual
  • 引擎廠商（engine manufacturer）service manual
  • Class society（如 IACS member）規定

遵循次序： 廠商建議 > 一般慣例

2. 定期 maintenance 項目： [src_examrules §8.1.B.19.b]

(i) 清潔 / 更換濾網： - Air filter（空氣濾網）— 每 100–250 hr 或視塞咗 - Fuel filter（燃油濾網）— 每 250–500 hr - Lube oil filter（油濾網）— 每換油時更換 - Sea suction strainer（海水入口濾網）— 定期檢查清

(ii) 更換潤滑油： - Engine oil 每 100–250 hr 或每年 - Gearbox oil 每 250–500 hr - 用適當 SAE viscosity（一般 SAE 30 / 40 marine grade）

(iii) 冷卻 + 排氣系統： - Heat exchanger 每年清 - 排氣管 + silencer check 漏 - Sea cock 試開閉

(iv) Belt drives： - Check tension（按下 1cm 為適） - Check 磨損 / 裂紋 - 備 spare belt

3. 額外 maintenance：

  • Anti-fouling paint 每年 / 兩年
  • Sacrificial anode（犠牲陽極）每年 check，腐蝕 50% 換新
  • Steering linkage greasing
  • Battery terminal 清理 + grease

4. Maintenance log： - 記錄每次 service 日期 + 項目 + 工時 - 後續分析 trend

5. 季前 / 季後 maintenance：

季前（春初）： - Engine 大 service - 試啟動 - 試所有電子設備 - 檢 LSA / FFA 過期

季後（冬季 lay-up）： - 排空冷卻系統 / 加 antifreeze - 燃油加 stabilizer - 拆 battery 充電 store - 升 dry storage（如可）

考試重點

冇單一明確 maintenance 數字考點，但題目可能問： - Maintenance manual 邊個寫？ → shipbuilder + engine manufacturer - 定期清咩濾網？ → air, fuel, lube oil, sea suction

易錯陷阱

  • 錯： 引擎未壞唔使 service——對： Preventive maintenance 預防大壞
  • 錯： 機油黑咗即換——對： 視乎 hours / 公里非顏色

B20 · Safe operation of deck equipment

點解要學

甲板裝備（絞車、錨機、舵、纜繩等）操作不當會傷人或令船失控。

核心知識

1. Anchor windlass（錨機）：

  • 操作前 check：絞鼓潤滑、stopper（防滑）、清潔
  • 落錨：慢慢放，避免 free fall（會傷人 + 損鏈）
  • 收錨：頂流 / 頂風慢慢上，避免 pull 太用力
  • 緊急鬆開：用 stopper 或 brake

2. Mooring winch（繫纜絞車）： - 揾啱 fairlead + bollard 角度 - 纜繩磨損 = stand clear - Snap-back zone（如纜繩斷裂彈出範圍）—— 唔好企 - ⚠ Whip lash injury 致命

3. Steering gear（舵機）：

機械式： - 鏈條 / cable / 齒輪 - 定期 grease

液壓式： - 油壓 reservoir 油位 - 防 air lock（B.13） - 過熱保護

電動式： - 防水 motor

4. Hydraulic deck winch（液壓絞車）： ⚠ B.35 考點（已喺 B18 提及）

油位過低 = 隔離 + 檢漏，唔好即注油

5. Davits / cranes： - 按 SWL（Safe Working Load）操作 - 定期 check 鋼纜

6. 安全操作原則： - 絕對唔可以 stand under load - 緊急 stop button 易取 - 操作員專心，唔分心 chat

考試重點

題目 答案
液壓絞車油位低？ 隔離 + 檢查漏點

易錯陷阱

  • 錯： 直接添油完事——對： 揾漏點先

B21 · Fire fighting and fire prevention

點解要學

火警喺船上是最致命災難之一。考試會出 4–5 題涵蓋火災理論、滅火器類型、燃料安全、LPG。

核心知識

1. Fire Triangle（火災三角）： ⚠ B.36 考點

    燃料 (Fuel)
       /\
      /  \
     /____\
燃燒溫度    空氣
(Heat)     (Oxygen)

3 元素缺一不可。 滅火 = 移除任何一邊。

B.36 答案 D：(i) + (ii) + (iii) 全部 = 燃料 + 空氣 + 燃燒溫度

2. 燃料火災危險：

(a) 汽油 (Petrol)： [src_examrules §8.1.B.21.a] - 揮發性極高，比空氣重，沉到艙底 - Flash point < 0°C — 室溫已易燃 - 4-min ventilation rule of thumb（唔係 PVOC 官方規則，但係國際 best practice）：開引擎前通風 4 分鐘

(b) 柴油 (Diesel)： - Flash point ~60°C，較安全 - 但仍可起火，霧化（spray）情況下尤其危險

(c) LPG（液化石油氣）： - 比空氣重 → 沉低處 → 通風口要喺底部

3. 火災分類 + 適當滅火劑： ⚠ A.35 / B.37 考點

Class 燃料 適當滅火 唔適當
A 木、紙、布 水、泡沫、乾粉 CO₂（無冷卻）
B 油、汽油、柴油、grease 泡沫、乾粉、CO₂ 水（油浮）
C 氣體（LPG） 乾粉、cut off supply 水
D 金屬 特殊 dry powder 水
E (電氣) 帶電器材 CO₂、乾粉 水、泡沫（導電）
F 食油 Wet chemical 水

⚠ A.35 考點：電氣火警 = CO₂ 最佳（不導電、無殘留、唔損電子）

⚠ B.37 考點：唔適合電氣火 = 泡沫（含水導電）

4. 攜帶式滅火器類型 + 操作 (PASS)：

操作 PASS 口訣： - Pull pin（拔保險銷） - Aim at base of fire（瞄火源底） - Squeeze handle（壓 trigger） - Sweep side to side（左右掃）

類型：

類型 內含 用 不用
Water 水 A 油 / 電氣
Foam 泡沫 A, B 電氣
CO₂ 二氧化碳 B, E A（無冷卻效果）
Dry powder 乾粉 A, B, C, E 食油
Wet chemical 化學液 F 電氣

5. 維護 (Maintenance)： - 壓力錶綠色區 - 每年由 authorized service agent 檢 - 操作後即重 fill / 換

6. 實戰滅火技巧： - 站上風（避免吸入濃煙） - 接近時保持低姿勢（熱氣浮高） - 設預定逃生路線 - 隊友支援 - 滅後監察 re-ignition

7. LPG 安裝同危險： ⚠ B.39 考點

規則： 1. ✓ 氣樽放陽光不直射處（避免溫升爆胎） 2. ✗ 石油氣管「最短為原則」係錯！ 應有適當長度（避免拉緊或受損）← B.39 答案 B 3. ✓ 櫃內氣樽：櫃底必須有透氣管（LPG 比空氣重，沉底） 4. ✓ 氣樽存於甲板上

LPG 漏氣處理： - 立即關主閥 - 唔可以開電 / 火 / 火花 - 通風（強制 fan） - 用 soap-water 揾漏點

8. 安全燃油儲存 + 火警時隔離供應： - 油缸有 emergency shut-off valve - 甲板有 main fuel cock - 火警 = 即關 fuel supply

9. 燃油洩漏處理： - 即關 fuel valve - 用吸油布 / sand 吸 - 通風 - 唔可以用水沖（油浮會擴散） - 通報海事處（屬污染）

10. 加油 (Refuelling) 注意：

  • 引擎熄火
  • 乘客落船
  • 唔吸煙、唔開電
  • 加油後通風 4 分鐘（rule of thumb）才開引擎
  • 加完 check 漏

11. 機房防火措施： ⚠ B.38 考點

包括： - 定期檢查沙箱、滅火器 - 定期消防演習 - 定期操練 emergency fire pump

⚠ 唔包括：發電機防過載——係維護事項而非防火措施。

B.38 答案 B

12. 排氣管隔熱： ⚠ B.20 考點

四大功能： - (i) 減熱輻射 - (ii) 降低機房溫度 - (iii) 防油類接觸引致火災 - (iv) 保護工人避免燒傷

全部都係，答 D
